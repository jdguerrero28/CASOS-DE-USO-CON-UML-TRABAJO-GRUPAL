#  Casos de Uso con UML

Este repositorio contiene la resolución de ejercicios en un trabajo grupal desarrollado por Juan Guerrero, Diego Torres y Jose Ramirez. Donde se han utilizado **Diagramas de Casos de Uso**, aplicando conceptos de relaciones de inclusión (`include`) y extensión (`extend`).

##  Tecnologías y Herramientas Usadas
Para el desarrollo de estos diagramas y la documentación, se utilizaron las siguientes herramientas:
* **[Lucidchart]**: Para la creación de los diagramas UML.
* **GitHub**: Para el control de versiones y hosting del proyecto.
